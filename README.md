[**Haystack**](https://github.com/deepset-ai/haystack) is an open source framework by [**deepset**](https://deepset.ai) for building production-ready **agentic, compound AI systems** like **advanced retrieval-augmented generative pipelines** and **multi-agent systems**.

This repository contains **fully functional applications** that demonstrate how to use Haystack to implement a range of use cases, from **advanced RAG solutions** to **practical agents**. Some of these applications are available online, while all of them can be run locally. For more details, visit [Haystack Demos](https://haystack.deepset.ai/overview/demo).

To build your own Haystack demo, you can use the [👾 Template for Haystack Apps with Streamlit](https://github.com/deepset-ai/haystack-streamlit-app).
